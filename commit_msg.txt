v0.3 - Weather forecast on Dashboard

Features:
- 5-day weather forecast from OpenWeatherMap API
- Forecast displayed on Dashboard Row 3 (full width)
- Compact weather cards with border and 1.5x size
- Day names, weather icons, temperature
- Timestamp conversion fix (seconds to milliseconds)

Dashboard changes:
- Removed "Умный дом" title and Settings button
- Clean header with widgets only

Architecture:
- OpenWeatherForecastResponse model for Forecast 2.5 API
- GetForecastUseCase in domain layer
- WeatherRepositoryImpl with daily forecast grouping
- Horizontal forecast cards with SpaceEven arrangement
