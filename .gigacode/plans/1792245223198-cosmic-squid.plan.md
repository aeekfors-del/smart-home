# План: Добавление возможности переименования устройств

## Контекст
Проект Smart Home на Android (Kotlin, Jetpack Compose, MVVM). Нужно добавить возможность пользовательского переименования устройств с хранением соответствия между оригинальными именами (от брокера) и пользовательскими.

## Требования
1. Хранить соответствие: `deviceId -> {originalName, customName}`
2. Добавить кнопку "Редактировать" на карточку устройства
3. Показать диалог с оригинальным и текущим пользовательским именем
4. Сохранять переименование в DataStore
5. При загрузке устройств применять пользовательские имена к оригинальным

## Архитектура изменений

### 6. UI Layer - ViewModel изменения

**Файл:** `app/src/main/java/com/besenok/smarthome/ui/screens/devices/DeviceListViewModel.kt`

**Добавить:**
```kotlin
@HiltViewModel
class DeviceListViewModel @Inject constructor(
    private val getDevicesUseCase: GetDevicesUseCase,
    private val renameDeviceUseCase: RenameDeviceUseCase,
    private val applyDeviceNamesUseCase: ApplyDeviceNamesUseCase
) : ViewModel() {
    
    private val _editingDevice = MutableStateFlow<Device?>(null)
    val editingDevice: StateFlow<Device?> = _editingDevice.asStateFlow()
    
    fun startRenameDevice(device: Device) {
        _editingDevice.value = device
    }
    
    fun confirmRenameDevice(newName: String) {
        val device = _editingDevice.value ?: return
        viewModelScope.launch {
            renameDeviceUseCase(device.id, newName)
            _editingDevice.value = null
            loadDevices()  // Перезагрузить для применения
        }
    }
    
    fun cancelRenameDevice() {
        _editingDevice.value = null
    }
    
    override fun loadDevices() {
        viewModelScope.launch {
            val result = getDevicesUseCase()
            _devices.value = result
            
            // Применяем пользовательские имена
            val devices = when (result) {
                is UiState.Success -> applyDeviceNamesUseCase(result.data)
                else -> emptyList()
            }
            
            val groupedDevices = groupDevicesByConnection(UiState.Success(devices))
            _groups.value = groupedDevices
        }
    }
}
```
