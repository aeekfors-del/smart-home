# План: Исправить обновление значений переключателей и цветов

## Проблема
Пользователь переключает Light и выбирает цвет RGB - команды отправляются в ioBroker, но:
1. Значение в UI не обновляется (показывает "Не подтверждено")
2. Цвет RGB остаётся "#000000"

## Причина
После отправки команды в брокер, UI не получает обновлённое значение от WebSocket. Состояние устройства должно обновиться через WebSocket, но этого не происходит.

## Решение

### 1. Проверить WebSocket обновление
**Файл**: `IobrokerWebSocketClient.kt`
- Убедиться, что WebSocket получает обновления от брокера
- Проверить логи WebSocket при переключении

### 2. Добавить обновление UI после отправки
**Файл**: `DeviceDetailViewModel.kt`
- После успешной отправки команды, принудительно перезагрузить устройство
- Или ждать подтверждения от WebSocket и обновлять UI

### 3. Улучшить отображение статуса
**Файл**: `DeviceDetailScreen.kt`
- Показывать спиннер при отправке
- Обновлять значение после подтверждения
- Для RGB - показывать выбранный цвет сразу

## Ключевые файлы
- `app/src/main/java/com/besenok/smarthome/ui/screens/devices/device_detail/DeviceDetailViewModel.kt`
- `app/src/main/java/com/besenok/smarthome/ui/screens/devices/device_detail/DeviceDetailScreen.kt`
- `app/src/main/java/com/besenok/smarthome/data/remote/iobroker/IobrokerWebSocketClient.kt`

## Верификация
1. Переключить Light - должно обновиться на "Вкл" с подтверждением
2. Выбрать цвет RGB - значение должно измениться на выбранный HEX
